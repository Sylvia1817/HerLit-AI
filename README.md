# HerLit AI

HerLit AI 是一个面向 Sylvia 的单用户女性文学内容工作台。目前重点是：研究女性作家与作品、生成小红书待审核文案、规划编辑感配图，并在人工确认后再进入图片制作流程。

## 当前产品边界

- 单用户、轻量级个人工具，不按 SaaS 设计。
- 每日内容必须经过人工审核，不自动发布到小红书。
- 审核前只生成文案与配图方案，不生成最终图片。
- 视觉基调为深墨绿 `#183d32`、暖象牙白 `#f4f0e8` 与少量朱红 `#a4472f`。
- 图片模型仅负责无字背景或编辑视觉；中文、书名、年份和引语使用确定性排版。

## 目录结构

- `app/`：HerLit AI Web 界面。
- `prompts/`：内容生成与审核规则。
- `daily/`：已生成的每日审核包与视觉样例。
- `素材/`、`project-data/`：品牌素材及可复用视觉资产。
- `backend/`、`worker/`、`db/`：后端、边缘运行与数据层的阶段性结构。
- `ROADMAP.md`：后续产品演进方向。

本地依赖、npm 缓存和临时输出位于 `runtime/`、`cache/`、`exports/`，不会提交到 GitHub。

## 本地运行

要求 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

验证构建：

```bash
npm run build
npm test
```

## 给协作者与 ChatGPT

优化时请优先阅读：

1. `app/page.tsx`：当前主要界面与交互。
2. `prompts/xiaohongshu_daily.md`：每日内容包规则。
3. `ROADMAP.md`：已规划的产品方向。
4. `daily/`：真实内容与视觉交付样例。

请保留“先审核、后生成图片、绝不自动发布”的人工把关机制，并优先改善真实可点击体验、内容核验、编辑工作流和视觉一致性。
