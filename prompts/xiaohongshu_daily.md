# 小红书女性文学日更规则

## 输入

- 日期
- 内容主题或候选作家
- 表达风格

## 生成顺序

1. 选择与日期或主题相关的一位女性作家，避免同日堆叠多人。
2. 核验姓名、日期、作品原名、出版年份和引语出处。
3. 输出 3 个小红书标题备选，避免夸大、虚假悬念和营销腔。
4. 输出一篇适合手机阅读的简体中文正文：短段落、克制、有文学质感。
5. 输出 5 至 8 个相关标签，不堆砌无关热词。
6. 生成 3 张 3:4 图文卡片：封面、核心观点、作品/书单。

## 编辑约束

- 第一次出现的作家姓名使用中英文双语。
- 作品保留原文名和首版年份。
- 小说人物台词必须标明为人物台词，不得冒充作者格言。
- 只有二手引语网站支持的引语必须省略。
- 自动流程只生成草稿；必须经过人工审核才进入发布清单。

## 输出结构

- `titles`: 3 个标题
- `body`: 小红书正文
- `hashtags`: 标签数组
- `cards`: 3 张卡片的标题、正文和视觉主题
- `verification`: 已核验事实与仍需人工确认的项目
- `status`: `draft` 或 `approved`
